# Examples: one page per theme

Each `examples/<theme>.html` is a page written for that theme's own world:
a Norton Commander file panel for `msdos`, the MAGI vote for `nerv`, a cue
list for `cue-lab`, an inventory screen for `pipboy`. The point is to show
what a theme is *for*, not the same demo in a different colour.

Open [`index.html`](index.html) from a static server at the repo root
(`python3 -m http.server`); each page links its self-contained
`dist/<theme>.css` bundle and nothing else. Compare a page against its
entry in [`references/`](../references/README.md).

## The rule

**Only ftl-themes classes and plain semantic HTML.** No `<style>` block, no
`style=""` attribute, no class the library doesn't define. That makes each
page an honest test of the library: whatever a page can't express is
something a third-party app would also have to write its own CSS for.

The pages are generated by [`scripts/build_examples.py`](../scripts/build_examples.py).
Edit the script, not the HTML, then run `python3 scripts/build_examples.py`.

## Checking a page

- **The rule itself:** `build_examples.py` refuses to write a page that
  contains a `<style>` block or `style=""`, or uses a class that no file in
  `core/` or `themes/` defines.
- **Rendered contrast:** [`scripts/audit_rendered.mjs`](../scripts/audit_rendered.mjs)
  measures every text element against the real pixels behind it, so it
  catches failures the token lint can't see (gradient buttons, glass,
  tinted badges, text on coloured bars). Needs Playwright:

  ```sh
  npm ci && npx playwright install chromium
  python3 -m http.server 8000 &
  npm run audit            # rendered contrast, fails below 4.5:1
  npm run audit:layers     # layered bundles render like the plain ones
  ```

  CI runs both on every push.

## What building these pages found

The first version of these pages exposed library gaps: no layout
primitives, levels only settable with inline styles, popovers that
couldn't be anchored, and no radio or inline-checkbox pattern. v3.11 added
`.ftl-stack`/`-cluster`/`-grid`, native `<meter>`/`<progress>` styling,
`.ftl-anchor`, `.ftl-radio`, `.ftl-radio-group` and `.ftl-check`, and the
pages now use them.

Muted text (labels, table headers, tabs) now meets WCAG AA like all other
text: `audit_rendered.mjs` reports no text below 4.5:1 on any page.
