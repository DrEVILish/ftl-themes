# Pending reference

These themes are pulled out of `themes/` and out of the build because no
reference screenshots have been captured for them yet in `references/`.
Once a theme gets a `references/<slug>/` folder with real images, move it
back with `git mv archive/themes-pending-reference/<slug> themes/<slug>`
and it re-enters the build the next time `scripts/build.sh` runs.

Removed from shipping on this pass: `aperture`, `blue-future`, `cue-lab`,
`material`, `nerv`, `pipboy`, `steampunk`, `tron`.
