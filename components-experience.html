Motion tokens

A theme describes how it moves with these. Every animation they drive runs only when the OS and data-motion allow it. Switching theme with the picker cross-fades through a view transition, and is instant under reduced motion.

TokenDefaultUsed for
--motion-duration-s120msHover, press, small state changes
--motion-duration-m200msSurfaces opening
--motion-duration-l320msTheme switch, splash exit
--motion-easecubic-bezier(0.2, 0, 0, 1)All of the above
--motion-entermotion-fade-in m ease bothAn element arriving (splash intro)
--motion-exitmotion-fade-out s ease bothAn element leaving

Accent swatches and seasons

The accent row in the panel lists the swatches the current theme declares (--accent-swatch-1 to -6); a theme without any hides the row. Try imac-g3 or cassette-futurism. Seasonal palettes (data-season) are the app's to switch on; a theme tints only its accent and gutter art for them.

Forced colours

Under Windows High Contrast (forced-colors: active) every theme falls back to system colours: surfaces drawn with shadows get a real outline, selected items use the Highlight colour, and focus rings stay. Nothing to switch on here; the OS does it.
