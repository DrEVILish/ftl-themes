Navigation and structure

Closable tabs, menu bar, tree, bottom tab bar, bottom sheet, nav rail, stepper, command palette, split pane and the keyboard layer. Every state is drawn by the theme; behaviour (closing, filtering, arrow keys) is the app's.

Closable tabs

.tabs.is-scroll keeps one row and scrolls sideways; a closable .tab wraps the tab button and its .btn-close. The add button sticks to the end.

Active tab, an unsaved tab (dot), an icon tab truncated at --tab-max, and overflow scrolling.

A strip that fits: the add button follows the last tab (icon form).

Menu bar

ul.menubar uses the nested-list markup of the context menu. Hover, focus or tap a top item; the second bar has File held open with aria-expanded="true".

Tree view

ul.tree with <details>: expand and collapse with no JS. The selected row uses aria-current.
