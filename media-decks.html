Physical media transports

A tape recorder built entirely from system components: seven-segment counter, VFD display, lamp-style transport keys, a labelled lamp band and a telemetry pane. The reel-to-reel drawing follows Pi9696’s original SVG; the vinyl, cassette and MiniDisc decks share the same states.

The transport keys are radio buttons: no JavaScript runs on this page. Connect the component to your app’s own transport by setting a state class instead.
