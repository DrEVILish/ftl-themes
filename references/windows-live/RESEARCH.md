# windows-live — reference design notes

Windows Live Essentials (Wave 3 2009 / Wave 4 2011) for Windows 7.

## What the captures show

- **Mail 2007 / 2009 splash** (`mail-2007-splash.jpeg`,
  `mail-2009-splash.png`): a glass panel (teal 2007, pale blue 2009) with
  the Windows flag, "Windows Live Mail" in light Segoe, a blue ring
  spinner and "Signing in…", over the Win7 swoosh.
- **Mail 2011 inbox** (`mail-2011-inbox.webp`): Scenic Ribbon with a blue
  "File" tab, Home/Folders/View/Accounts tabs, big icon buttons grouped
  (New, Delete, Respond, Actions, Tools); left pane with "Quick views",
  account folders and a Mail/Calendar/Contacts/Feeds switcher; message
  list; calendar on the right; pale status bar "1 message(s), 0 unread"
  and "Working online".
- **Mail add account** (`mail-add-account.jpeg`): white dialog with a
  pale-blue aurora header, a green Segoe UI Light title, small grey help
  text, Win7 text fields and checkboxes, Cancel/Next bottom right.
- **Messenger 2011 sign-in** (`messenger-2011-sign-in.jpg`): aurora
  header, "Sign in to / Windows Live **Messenger**" (light + semibold),
  a big display picture in a glossy green rounded frame, blue links,
  availability dropdown with a green dot, Win7 buttons.
- **Messenger contacts / conversation** (`messenger-2011-contacts.webp`,
  `messenger-conversation-emoticons.avif`): pale-blue headers with
  scenes, green-framed avatars, contact list with status icons, emoticon
  picker grid.
- **Photo Gallery / Movie Maker** (`photo-gallery-ribbon.jpeg`,
  `movie-maker-*.jpg/png`): ribbon with grouped large icons, white work
  areas, storyboard tiles in pale-blue frames, blue round play buttons,
  Win7 zoom slider in the status bar.
- **Live Gallery web** (`gallery-web.png`) and **logo**
  (`logo-mail.jpeg`): the four-colour flag and wordmark.

## Palette (sampled by eye)

- Application button blue `#2f6fc2`→`#1a54a3` (reference brighter,
  ≈`#4f8fd9` top); ribbon tab frame `#b6bccc`; ribbon strip white →
  `#e3ebf6`.
- Pane frames `#c5d2df`; pane header `#fafcfe`→`#e8eff8`; heading blue
  `#1e395b`; title green `#2b7a2b`; link blue `#1e6fbf`.
- Selection `#e5f3fd`→`#cce8ff` with `#99d1ff` frame (Explorer).
- Presence green `#7ad65a` with `#3f9a1e` edges.
