# TOS / TOS films references: index

Screen-used Okudagram recreations collected by http://www.lcars.org.uk/ (credit lcars.org.uk). Reviewed image by image on 2026-10-01. Most are ~200 px thumbnails, so scores top out around 8.

This is not LCARS: it is a different Star Trek interface language with no theme yet, kept as reference for a future theme.

## How this set was culled

Each capture was tagged with the 1-3 UI components it *uniquely* shows off (primary first) and scored 0-10 for how well it represents them. Then:

1. **Score below 5 deleted** (10).
2. **Near-duplicates deleted** (1), keeping the larger file.
3. **Already covered, deleted** (31): within each source gallery, best-first, an image was dropped when a kept image of equal or higher score already shows all of its components.

**35 kept.** Filenames are the tag list: camelCase component names, `-` between components, primary first (`elbowFrame-pillButton.webp`).
