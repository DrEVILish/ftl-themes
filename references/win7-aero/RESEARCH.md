## Window colour (glass tint)

Windows 7's *Personalize → Window Color* let the user pick the glass
colour; it tints the title bar, frame, taskbar and Start menu glass
(intensity slider and transparency on/off too). The 16 presets, with
their approximate colorization values (ARGB, from the registry
`ColorizationColor`; community-collected, not an official table):

| Name | Hex | | Name | Hex |
|---|---|---|---|---|
| Sky (default) | `#74b8fc` | | Fuchsia | `#ff0099` |
| Twilight | `#0046ad` | | Blush | `#fcc7f8` |
| Sea | `#32cdcd` | | Violet | `#6e3ba1` |
| Leaf | `#14a600` | | Lavender | `#b0a5d8` |
| Lime | `#97d937` | | Taupe | `#d1c79f` |
| Sun | `#fadc0e` | | Chocolate | `#4e0000` |
| Pumpkin | `#ff9c00` | | Slate | `#555555` |
| Ruby | `#ce0f0f` | | Frost | `#fcfcfc` |

## Explorer references (described; files to be added to this folder)

- Explorer window: glass title area with no caption text, back/forward
  round glass buttons, breadcrumb address bar ("Libraries ▸ Documents ▸")
  with a refresh button, search box at the right with a magnifier.
- Command bar under it: pale blue gradient strip with "Organize ▾",
  "Open ▾", "Share with ▾", "Print", "E-mail", "Burn", view toggle,
  preview-pane and help icons at the right.
- Navigation pane: Favorites / Libraries / Homegroup / Computer / Network
  groups with small icons, white background; selected item pale blue.
- Content: "Documents library" heading in green-blue (#1e395b-ish) with
  "Arrange by: Folder ▾" link; details view with column headers, pale
  blue hover/selection with a 1px #7da2ce frame; large-icon view.
- Details pane at the bottom: pale blue gradient with a large thumbnail
  and metadata pairs.
- Start menu: two-column, left white (program list, search box "Search
  programs and files"), right tinted glass (Documents, Pictures, Music,
  Games, Computer, Control Panel…), Shut down button with ▸.
- Taskbar: dark glass with the round Start orb and large pinned icons.
