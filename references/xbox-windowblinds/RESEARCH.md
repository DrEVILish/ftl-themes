# xbox-windowblinds — reference notes (no theme yet)

The **Official Xbox WindowBlinds theme**: The Skins Factory was contracted by
Microsoft's Xbox team to make a full skin suite (WindowBlinds visual style,
wallpaper and a Windows Media Player skin) for Windows 98/ME/2000/XP. The
skin file is dated 24 July 2002. Found while researching the Alienware
AlienGUIse suites (same designer, same era); kept here for a possible
future theme.

- `xboxSkin-desktop-startMenu-titleBar.jpg` — the promotional capture
  (729×583, JPEG, so colours are indicative): black glass title bars and
  frames with lime caption buttons, a black two-column Start menu with a
  green user tile, a lime-lit Explorer and the Xbox console wallpaper.
