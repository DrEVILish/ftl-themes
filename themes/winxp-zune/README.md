# Windows XP Zune

> Matte charcoal frames, stark white text, glowing orange highlights.

## What this theme is trying to achieve

The moody counter-culture sister to Luna: XP's chrome stripped of its blue
gloss and rebuilt matte black, with a single hot accent doing all the work
Luna spread across gradients and bevels.

## Core values

1. **Matte, not glossy.** Flat charcoal fills; no gradient anywhere except
   the orange glow itself.
2. **One accent, used deliberately.** Orange marks headings, focus, the
   nav rule and primary actions — nothing else is coloured.
3. **White text, not off-white.** The contrast is meant to feel stark.
4. **The glow is restrained** — a soft shadow, not a bloom. This is mood
   lighting, not a HUD.

## Layout

A dark, minimal bar with a 2px orange rule underneath, ordinary padding,
and a status strip carrying the accent as its text colour rather than its
background — quiet by default, warm at the edges.

## Tell-tales of an inauthentic result

- Any gradient on a button or panel → this isn't Luna's gloss language.
- More than one accent hue in view at once.
- A bright, saturated background — this palette stays near-black throughout.
